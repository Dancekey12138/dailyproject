## 项目概述

ai-image-caption-pro 是一个Python语言开发的开源项目项目。

### 核心功能

- `IPTC:Caption-Abstract` — AI caption, appended to any existing caption
- `IPTC:Keywords` + `XMP-dc:Subject` — deduplicated, merged with existing keywords
- `XMP-lr:HierarchicalSubject` — for Lightroom keyword hierarchy
- `XMP:Description`, `XMP:Creator`, `XMP:Rights` — mirrored from identity settings
- `XMP-iptcExt:AltTextAccessibility` — for CMS / screen readers

# AAI2Lama

**项目链接**: [GodModeAI2025/AAI2Lama](https://github.com/GodModeAI2025/AAI2Lama)

## 基本信息

- **⭐ Stars**: 1
- **🔤 主要语言**: Swift
- **🏷️ 标签**: apple-intelligence, foundation-models, llm, macos, ollama
- **📝 简介**: Apple Intelligence as an Ollama-compatible model. Use Apple's on-device Foundation Model with any Ollama or OpenAI client.

## 项目概述

AAI2Lama 是一个Swift语言开发的AI/机器学习项目。

### 核心功能

- Runs Apple's on-device ~3B Foundation Model via the `FoundationModels` framework
- Exposes it as `apple-intelligence:latest` through standard APIs
- **Ollama API** — `/api/chat`, `/api/generate`, `/api/tags`, `/api/embed`, `/api/show`, `/api/ps`
- **OpenAI API** — `/v1/chat/completions`, `/v1/models`, `/v1/embeddings`
- Streaming (NDJSON + SSE), tool calling, embeddings (via `NLEmbedding`)

## 基本用法

### 安装

```bash
# 克隆仓库
git clone https://github.com/GodModeAI2025/AAI2Lama.git
cd AAI2Lama

# 安装依赖（根据项目实际情况）

# 或

```

### 快速开始

